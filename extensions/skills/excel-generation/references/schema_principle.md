# Excel 建表设计准则

> 本准则是 `excel-generation` 技能的底层约定。所有 xlsx 产物应遵循以下结构、样式与公式原则,确保在 Excel/WPS 中可编辑、在 SheetJS 预览中可读、在 recalc 校验中零错误。

## 1. 工作簿结构

- **sheet 数量**: 至少 1 个,常规任务 2–3 个(明细 + 汇总)。不要为一个表格硬拆多个 sheet。
- **sheet 命名**: 中文、无特殊字符、长度 ≤31 字符。推荐: `预算`、`明细`、`汇总`、`进度`、`统计卡`。
- **激活 sheet**: 默认激活第一个 sheet(`wb.active = ws1`)。
- **默认列宽**: 未指定时 A/B/C/D 列宽分别 12/14/14/12,其余 10;数字列可更宽以容纳千分位。

## 2. 表头与数据区

- **表头行**: 固定第 1 行;字体加粗、水平居中、垂直居中。
- **表头底色**: 使用浅蓝灰 `DCE6F1`(RGB),统一 solid 填充。
- **数据起始行**: 从第 2 行开始;脚本中用常量 `DATA_START = 2` 声明。
- **汇总行**: 放在数据区下方第一行空行,字体加粗,可填浅灰 `F2F2F2`。
- **冻结首行**: 数据行超过 10 行时冻结首行(`ws.freeze_panes = "A2"`)。

## 3. 列类型与数字格式

| 类型 | 示例 | number_format |
|---|---|---|
| 整数 | 数量、人数 | `0` |
| 两位小数 | 金额、单价 | `#,##0.00` |
| 百分比 | 占比、完成率 | `0.00%` |
| 日期 | 开始/结束日期 | `yyyy-mm-dd` |
| 文本 | 名称、状态 | `@` 或不设置 |

- 金额列右对齐,文本列左对齐,表头居中。
- 状态列(如“已完成/进行中/未开始”)使用中文文本,不要写布尔值。

## 4. 公式原则

- **所有汇总必须写公式**,不能用 Python 算好后写死。
- **常用公式模板**:
  - 合计: `=SUM(B2:B10)`
  - 平均(带零保护): `=IF(COUNT(B2:B10)=0,0,AVERAGE(B2:B10))`
  - 占比(带零保护): `=IF($B$11=0,0,B2/$B$11)`
  - 条件判断: `=IF(B2>=100,"达标","未达标")`
  - 查找: `=IFERROR(VLOOKUP(A2,明细!A:B,2,FALSE),"未找到")`
- **分母保护**: 任何除法、平均、占比公式都要处理分母为 0 或空的情况,否则 recalc 会报 `#DIV/0!`。
- **错误包装**: 对外部不可控数据使用 `IFERROR(...,"-")`,但内部数据一致性应通过零保护解决,不要滥用错误包装掩盖逻辑问题。
- **跨 sheet 引用**: 使用 `明细!A1:B10` 写法,sheet 名含空格时用单引号 `'明细表'!A1`。

## 5. 样式原则

- **字体**: 中文用“微软雅黑”或“等线”;英文/数字用“Calibri”。字号默认 11,表头 12。
- **边框**: 数据区使用细边框(`thin`),颜色 `000000`。
- **列宽**: 按内容自适应,但至少比表头文字宽 2 个字符;不要依赖自动列宽(耗时且不稳定)。
- **颜色常量**: 全部用 6 位十六进制,如:
  - 表头蓝: `DCE6F1`
  - 汇总灰: `F2F2F2`
  - 警告黄: `FFF2CC`
  - 完成绿: `E2EFDA`
  - 风险红: `FCE4D6`
- **不设置条件格式一期**: 如需高亮,用固定填充色行或列,避免条件格式带来的重算/预览差异。

## 6. 可读性与交付

- **打印区域**: 常规表不需要设置,若用户要求打印,设置 `ws.print_area = "A1:D30"`。
- **批注**: 对关键公式或假设加批注,说明计算口径,如“占比=单项金额/合计金额,分母为零时显示 0”。
- **产物干净**: 交付后工作区只保留 `.xlsx`,脚本与中间文件放在 `.<文件名>.ref/` 隐藏目录,用户需要时可清理。
- **不残留密码/保护**: 一期不对工作簿或工作表加保护密码。

## 7. 禁止事项

- 禁止在脚本中 `pip install`。
- 禁止 `subprocess`、`os.system`、`eval`、`exec`。
- 禁止把 Python 计算结果当“公式”写死。
- 禁止写入外部引用(如 `=[其他文件.xlsx]Sheet1!A1`),recalc 会报 engine error。
- 禁止使用动态数组/溢出函数(`UNIQUE`、`FILTER`、`SORT`、`SEQUENCE` 等),formulas 引擎不支持,recalc 会报 engine error。
