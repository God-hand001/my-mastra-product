# 预算表范式

## 适用场景

需要按类别列出收入/支出、计算小计/合计、占比,并可按月份/部门拆分 sheet。

## 推荐结构

```
Sheet: 预算
A1: 类别     B1: 项目     C1: 预算金额    D1: 实际金额    E1: 差额      F1: 占比
A2: 人力成本  B2: 工资     C2: 50000       D2: 48000       E2: =C2-D2    F2: =IF($C$8=0,0,C2/$C$8)
... (若干行)
第 N 行: 合计  B_N: 合计    C_N: =SUM(C2:C_{N-1})  ...
```

## 公式模板

- 差额: `=C2-D2`
- 占比(带零保护): `=IF($C$8=0,0,C2/$C$8)`
- 合计行: `=SUM(C2:C7)`
- 总预算/实际: `=SUMIF(A:A,"收入",C:C)`(如需分收入/支出)

## 样式模板

- 表头: 加粗、居中、填充 `DCE6F1`。
- 金额列: 右对齐、`#,##0.00`。
- 占比列: 右对齐、`0.00%`。
- 合计行: 加粗、填充 `F2F2F2`、上边框 `thin`。
- 列宽: A=12, B=18, C-F=14。
- 冻结首行: `ws.freeze_panes = "A2"`。

## 多 sheet 变体

- `预算` sheet: 全年汇总。
- `1月`、`2月`…: 各月明细,汇总行公式引用当月数据。
- 全年汇总中的各月小计可引用 `=SUM('1月:12月'!C2)`(仅当所有月份 sheet 结构一致)。
