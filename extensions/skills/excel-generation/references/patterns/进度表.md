# 进度表范式

## 适用场景

任务/项目排期,需要展示开始日期、结束日期、完成百分比、剩余天数、状态判定。

## 推荐结构

```
Sheet: 进度
A1: 任务名称  B1: 负责人  C1: 开始日期   D1: 结束日期   E1: 完成率   F1: 状态
A2: 需求分析   B2: 张三    C2: 2026-09-01 D2: 2026-09-05 E2: 100%    F2: =IF(E2>=1,"已完成",IF(E2>0,"进行中","未开始"))
...
```

## 公式模板

- 状态: `=IF(E2>=1,"已完成",IF(E2>0,"进行中","未开始"))`
- 剩余天数(带完成率): `=IF(E2>=1,0,MAX(0,D2-TODAY()))`
- 总工期: `=D2-C2+1`
- 加权进度: `=SUMPRODUCT(E2:E10,D2:D10-C2:C10+1)/SUM(D2:D10-C2:C10+1)`(日期相减得数字,可用)

## 样式模板

- 表头: 加粗、居中、填充 `DCE6F1`。
- 日期列: 居中对齐、`yyyy-mm-dd`。
- 完成率列: 右对齐、`0%` 或 `0.00%`。
- 状态列: 文本居中;完成行可填 `E2EFDA`(绿),进行行 `FFF2CC`(黄),未开始行 `F2F2F2`(灰)。
- 列宽: A=20, B=12, C/D=14, E/F=12。
- 冻结首行: `ws.freeze_panes = "A2"`。

## 注意事项

- 日期用 `datetime.date` 写入,`number_format = "yyyy-mm-dd"`。
- 完成率以小数写入(如 0.75),显示为 75%。
- 不要跨 sheet 引用日期做减法,formulas 对日期运算支持有限,尽量在同一 sheet 内完成。
