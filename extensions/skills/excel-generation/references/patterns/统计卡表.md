# 统计卡表范式

## 适用场景

需要从多维度汇总数据,并在顶部用“卡片”形式展示核心指标,下面用明细表支撑卡片数字。

## 推荐结构

```
Sheet: 统计卡
A1:D1 合并: 本月总销售额        E1:H1 合并: 订单数        I1:L1 合并: 客单价
A2:D2 合并: =SUM(B10:B100)      E2:H2 合并: =COUNTA(A10:A100)
I2:L2 合并: =IF(E2=0,0,A2/E2)

A4: 日期     B4: 品类     C4: 销售额    D4: 订单数    E4: 客单价
A5: ...
```

## 公式模板

- 总销售额: `=SUM(C5:C100)`
- 订单数: `=COUNTA(A5:A100)` 或 `=SUM(D5:D100)`
- 客单价(带零保护): `=IF(E2=0,0,A2/E2)`
- 品类汇总: `=SUMIF(B5:B100,"电子",C5:C100)`
- 同比/环比(若提供上期数据): `=IF(B2=0,"-",(A2-B2)/B2)`

## 样式模板

- 顶部卡片区:
  - 合并单元格、字号 16、加粗、数值右下对齐。
  - 背景色: 销售额 `E2EFDA`(绿), 订单数 `DCE6F1`(蓝), 客单价 `FFF2CC`(黄)。
  - 卡片之间留一列空列做视觉分隔。
- 明细表头: 加粗、居中、填充 `DCE6F1`。
- 金额列: 右对齐、`#,##0.00`。
- 列宽: A=14, B=14, C/D/E=16。
- 冻结明细表头: `ws.freeze_panes = "A5"`。

## 多 sheet 变体

- `统计卡` sheet: 顶部卡片 + 关键明细。
- `明细` sheet: 完整数据,统计卡中的汇总公式可跨 sheet 引用: `=SUM(明细!C:C)`。
- `趋势` sheet: 按日期/月份的折线数据(仅数值表,一期不画图)。

## 注意事项

- 卡片数值必须来自公式,不要直接写 Python 计算结果。
- 合并单元格只用于展示,不要参与后续公式引用(合并后引用取左上角单元格)。
- 客单价、占比等公式必须带零保护,否则 recalc 报 `#DIV/0!`。
