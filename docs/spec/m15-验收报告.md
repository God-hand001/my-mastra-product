# M15 场景工作台角色切换 验收报告

## 执行方式说明

M15 全程由 codex 子代理完成三批编码（批 1 角色配置+RoleSelector、批 2 请求链路+artifact 标签+渲染器路由、批 3 ask_user+问题面板），主 agent 负责 T0（zustand 安装、4 角色 systemPrompt 文案撰写）、指令书派发、每批交付物的**逐文件核对**与 T8 端到端验收。

**验证手段分级**（同 M14 报告口径）：
- **API 实测**：主 agent 通过 curl 直连后端 `/chat/agent`，以真实 LLM 对话驱动各角色，从流式响应/落库消息/挂起列表取证
- **代码级验证**：读代码 + 批 2/3 的单元用例 + 编译构建
- **需用户目测**：浏览器交互类（选择器观感、面板渲染、点击流转），主 agent 无浏览器自动化工具，无法代验
