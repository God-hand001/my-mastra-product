# M6 内置浏览器 Checklist

> 前置:[m6-spec.md](./m6-spec.md)、[m6-plan.md](./m6-plan.md)、[m6-task.md](./m6-task.md) 已确认

## 验证责任划分(先读这段)

`webview` 只存在于 Electron,**无法用 headless 浏览器自动化验证**。因此下列条目按验证方式分成三组:

| 组 | 谁验证 | 方式 |
|---|--------|------|
| A 纯逻辑 | Claude | node 脚本断言,贴出实际输出 |
| B 编译构建 | Claude | `tsc --noEmit` + `npm run build` + `node --check` |
| C 桌面端行为 | **用户** | 启动 `cd app-desktop && npm run desktop:dev`(需后端在 4111 运行、前端 dev 在 5173),按步骤操作并观察 |

C 组无法由 Claude 自动执行 —— 起 Electron 窗口并驱动 webview 内的真实网页超出其工具能力。声称"已验证"即为虚报,必须由用户实测。

## A 纯逻辑(Claude 验证)

- [ ] **A1** 地址解析:域名形态自动补协议(验证:`resolveUrlInput('mastra.ai')` → `{kind:'url', url:'https://mastra.ai'}`)→ 对应 AC2
- [ ] **A2** 地址解析:完整 http/https 原样通过(验证:`resolveUrlInput('https://a.com/p?q=1')` → `kind:'url'` 且 url 不变)
- [ ] **A3** 地址解析:关键词走搜索(验证:`resolveUrlInput('mastra 框架')` → `kind:'search'`,url 含搜索引擎域名与编码后的关键词)→ 对应 AC2
- [ ] **A4** 地址解析:伪协议被拒(验证:`resolveUrlInput('javascript:alert(1)')` 与 `resolveUrlInput('file:///C:/')` 均返回 `kind:'rejected'` 且带中文理由)→ 对应 AC9
- [ ] **A5** 地址解析:空输入被拒(验证:`resolveUrlInput('   ')` → `kind:'rejected'`)
- [ ] **A6** 网页标记解析:合法标记可解析(验证:`parseWebPages('文字【网页:Mastra 官网#https://mastra.ai】')` 返回 1 项,title/url 正确)→ 对应 AC6
- [ ] **A7** 网页标记解析:非法网址被过滤(验证:`parseWebPages('【网页:恶意#javascript:alert(1)】')` 返回 0 项)→ 安全底线,模型输出不可信任
- [ ] **A8** 标记清洗:清洗后文本不含标记(验证:`stripWebPageMarkers` 处理含标记文本,输出中搜不到 `【网页:`)

## C 桌面端行为(用户验证)

### C-1 基础浏览

- [ ] **C1** 打开浏览器标签后可见地址栏与后退/前进/刷新控件,渲染区显示网页内容,标签标题与页面标题一致(操作:新标签页地址栏输入 `mastra.ai` 回车)→ AC1
- [ ] **C2** 关键词搜索可用(操作:地址栏输入 `mastra 框架` 回车 → 打开搜索引擎结果页)→ AC2
- [ ] **C3** 新标签页输入框双重用途:输入 `docx` 但**不回车**时,下方「最近文件」按输入过滤;回车后进入浏览器视图 → AC3
- [ ] **C4** 首次打开页面时后退按钮为置灰态;点击页内链接后后退变可用,点击后退回到上一页 → AC7
- [ ] **C5** 加载中显示停止按钮,加载完成后变为刷新按钮;点击停止能中断加载 → AC7
- [ ] **C6** 访问不存在的域名(如 `https://this-domain-does-not-exist-12345.com`),渲染区显示错误码与描述及「重试」按钮,点击重试重新发起加载,不留白屏 → AC8
- [ ] **C7** 地址栏输入 `file:///C:/` 或 `javascript:alert(1)`,显示中文拒绝提示且**页面未发生跳转** → AC9

### C-2 架构关键点(不通过则 plan 的核心决策落空)

- [ ] **C8** 标签切换不丢导航状态(操作:在浏览器标签内连续访问两个页面 → 切到另一个标签 → 切回来。预期:页面**没有重新加载**、后退按钮仍可用、滚动位置保留)→ 对应 plan「常驻挂载」决策
- [ ] **C9** 渲染隔离生效(操作:在 webview 内打开任意页面,通过 Electron 开发者工具在该 webview 的 console 执行 `typeof window.jlcDesktop`。预期:`undefined`,即网页拿不到 preload 桥)→ N1
- [ ] **C10** 页面内新窗口请求不弹系统窗口(操作:访问任一含 `target="_blank"` 外链的页面并点击。预期:不弹出新的 Electron/系统窗口)→ N3

### C-3 agent 联动

- [ ] **C11** 页面内容交给 agent(操作:浏览某页面 → 点工具栏「交给 agent」。预期:对话输入框被填入含页面标题、网址与正文摘录的文本,且**未自动发送**)→ AC5
- [ ] **C12** agent 主动开页(操作:让 agent 联网搜索某话题并要求展示来源页面。预期:右侧自动打开该网址的浏览器标签;消息气泡内显示网页卡片而**非**原始 `【网页:...】` 文本;点击卡片可重新打开)→ AC6
- [ ] **C13** 打开含网页标记的旧会话时,面板**不自动展开**(操作:C12 完成后切到别的任务再切回来。预期:预览面板保持关闭状态,标签在但不弹出)→ 对应 `reveal:false` 的历史扫描约定

### C-4 复用与不回退

- [ ] **C14** 浏览器标签支持既有面板能力:缩放按钮、全屏、弹出独立窗口均可用 → N4
- [ ] **C15** 既有功能未回退(操作:依次验证 —— 打开工作区 .docx 文件预览正常、让 agent 生成一个文件后产物标签自动打开、点「任务摘要」图标摘要正常加载、新回复底部显示耗时与 token)→ AC10、N5
- [ ] **C16** 非桌面端提示(操作:用 Chrome 直接打开 `localhost:5173` 并打开浏览器标签。预期:显示「内置浏览器需在桌面端使用」提示,不是空白块)→ AC4

## 端到端场景(用户验证)

- [ ] **E1 浏览 → 提问闭环**:地址栏输入 `mastra.ai` 回车 → 页面渲染 → 点「交给 agent」→ 输入框出现页面内容 → 补一句「用三句话总结这个框架」→ 发送 → agent 基于页面内容作答。
- [ ] **E2 搜索 → agent 开页 → 追问**:向 agent 提一个需要联网的问题 → agent 搜索后在回复末尾给出网页标记 → 右侧自动打开该页面并显示网页卡片 → 在该页面点「交给 agent」→ 追问细节。
