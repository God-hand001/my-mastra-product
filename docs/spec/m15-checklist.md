# M15 场景工作台角色切换 Checklist

> 每项通过运行代码或观察行为验证。主 agent 执行，先有证据再下结论。

## 编译与构建

- [ ] 后端编译无错误（验证：根 `npx tsc --noEmit` 退出码 0）
- [ ] 前端编译与构建无错误（验证：`cd app && npm run build` 成功）
- [ ] zustand 已安装（验证：`cd app && npm ls zustand` 显示版本）

## 角色选择与锁定

- [ ] 选择器位置与形态（验证：AC1——新任务时工具栏连接器右侧出现胶囊「图标+角色名+▾」，菜单 4 项图标+名称+当前绿勾，无描述文字）
- [ ] 角色锁定（验证：AC6——发出首条消息后选择器消失，会话内不再出现；历史消息不受影响）
- [ ] 会话恢复（验证：AC7——切换回已锁定会话不显示选择器且右侧按该会话角色渲染；重启应用后仍恢复）
- [ ] 新任务默认通用（验证：F4/F6——新建任务选择器显示「通用」）

## 请求链路

- [ ] 角色指令生效（验证：让设计角色"自我介绍你能做什么"——回复体现网页设计能力与产物约定；general 角色同等提问无产物约束表述）
- [ ] 技能白名单（验证：F8——design 角色下询问可用技能，结果不含白名单外技能；斜杠显式指定技能仍可使用）
- [ ] 请求体携带（验证：抓请求确认 requestContext 含 role 字段且随切换变化）

## 产物协议

- [ ] html 产物剥离与渲染（验证：AC2——设计角色产出 `<artifact type="html">`，聊天流无大段代码，右侧 iframe 渲染，可源码/预览切换）
- [ ] 沙箱安全（验证：AC3——iframe sandbox="allow-scripts allow-forms" 且无 allow-same-origin）
- [ ] slides 工作流（验证：AC4——先大纲后产物，右侧幻灯片工作区渲染 1280 画布；导出 PPTX 得到文件）
- [ ] doc 产物（验证：AC5——写作角色产出 doc 产物，右侧渲染，导出 Word 可打开）
- [ ] 兜底（验证：AC9——要求纯文字回答时正常 Markdown 展示，无报错无空产物卡）
- [ ] type 补齐（验证：AC10——构造缺 type 的标签，按当前角色 artifactType 正确路由）

## 结构化提问

- [ ] 提问触发与面板（验证：AC13——设计角色说「做一个房屋设计」，右侧出现「问题」标签渲染表单，状态行显示等待回答）
- [ ] 提交恢复（验证：AC13——提交答案后模型按答案继续执行）
- [ ] AI 自行决定（验证：AC13——该按钮跳过提问，模型自行决策继续）
- [ ] general 不暴露（验证：AC13——通用角色下模型无 ask_user 工具可用）
- [ ] 无双重执行（验证：AC14——挂起期间再发消息不产生新回复流，提交后统一恢复）

## 非功能

- [ ] 兼容现状（验证：AC8——general 角色请求与 M12 完成时行为等价：无额外约束、【产物:】机制、技能指定、模型选择均不变）
- [ ] 扩展性（验证：AC11——临时新增第 5 个假角色仅改配置数组即出现在选择器并生效，验证后移除）
- [ ] 注入安全（验证：N2——产物内容含 script 标签时在沙箱内执行而非宿主页；代码走查无 dangerouslySetInnerHTML 新增）
- [ ] 文本安全（验证：N2——产物 title 含 HTML 特殊字符按纯文本显示）
