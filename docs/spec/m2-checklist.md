# M2 个人网盘 + 文档问答 Checklist

> 每一项通过运行代码或观察行为来验证。括号内为验证方式;[ACx] 对应 spec 验收标准。

## 实现完整性

- [ ] docx 上传解析:文本提取正确、回答基于内容(验证:上传嘉立创介绍 docx → "总结要点",[AC1])
- [ ] PDF 上传解析:总结/提问正常(验证:上传任意 PDF,[AC2])
- [ ] xlsx 上传解析:数据类问题回答正确(验证:构造小 Excel → "哪列总和最大",[AC3])
- [ ] 不支持格式明确提示(验证:上传 png → 提示"不支持的文件类型",[AC4])
- [ ] 从网盘选择附件(验证:新任务"+"→"从网盘选择"→ 问答正常,[AC5])
- [ ] 网盘页列表/删除/下载(验证:名称/大小/时间显示;删除消失;下载可打开,[AC6])
- [ ] 超大文本明确报错(验证:构造 >30 万字符 txt → "文件过大",[AC7])
- [ ] 多文件对比(验证:两个文件附件 → "对比这两份材料",[AC8])
- [ ] workspace 隔离(验证:上传后 workspace/ 无新文件,[AC9])

## 集成

- [ ] 附件文件名/大小/时间在网盘页与附件条一致(验证:目测)
- [ ] 历史持久化:带附件的任务刷新后,附件全文仍在历史中(验证:刷新页面)
- [ ] 附件条上限 5 个生效(验证:选第 6 个被禁用)
- [ ] M0/M1 无回归:建任务、流式、工具卡片、联网搜索抽查(验证:各一轮)
- [ ] 提交后原始文件落盘 storage/drive/(验证:目录可见,含 meta.json)

## 编译与质量

- [ ] 后端启动无报错(验证:npm run dev 日志)
- [ ] 前端 tsc + vite build 通过(验证:app/ 下构建)
- [ ] .gitignore 含 storage/(验证:git status 不出现 storage)
- [ ] 路径穿越防护(验证:上传名为 `../../x.txt` 的文件被清洗,存储路径无逃逸)

## 端到端场景

- [ ] 场景 1(主流程):首页"+"上传 docx → 附件条 → 提交 → 回答基于文档 → 追问深入 → 刷新历史完整
- [ ] 场景 2(混合):带附件任务里同时联网搜索(如"这份文档提到的公司最近有什么新闻")→ 搜索+附件同时工作
- [ ] 场景 3(网盘管理):上传 3 个文件 → 网盘页管理 → 下载对比原件 → 删除
- [ ] 场景 4(故障):png 拒绝、损坏 docx 明确报错、超大 txt 阻断,界面均不崩溃
