# M14 右栏任务监控面板 Spec

## 背景

右侧预览栏目前有一个「任务摘要」标签页：调用后端 AI 生成当前任务的文字摘要。信息量有限且每次要等生成。

本产品把右侧栏的「任务摘要」升级为「任务监控」：实时呈现 Agent 执行任务的过程状态，包含四个板块——待办（模型执行过程中的任务清单，完成项划横线）、产物（分为最终文件与工作文件，产物右侧的图标点击可打开产物所在的本机文件夹）、技能与 MCP（本次任务用到的技能与 MCP 连接器工具）、意识更新（短期记忆与长期记忆的状态）。

数据源现状：
- 待办：Agent 内置待办工具会以 signal 消息（current-task-list / task-list-update）落库到会话消息中，前端已有解析过滤逻辑（当前是过滤掉不渲染），数据可反向利用
- 最终产物：消息文本中的【产物:】标记（M13 已有解析）；工作文件：Agent 执行命令时写入沙箱 workspace 的中间文件，可通过现有 workspace 目录列举端点获取
- 技能与 MCP：会话消息中的工具调用记录（skill 工具调用 = 技能；连接器命名空间工具 = MCP）
- 意识更新：短期记忆映射为当前任务上下文占用与压缩状态（已有上下文用量端点）；长期记忆映射为跨任务的记忆摘要状态（当前实现中体现为会话标题与压缩摘要的存在状态）

## 目标

- 右栏「任务摘要」标签页替换为「任务监控」，一屏看到任务推进状态
- 待办清单与模型执行实时同步，完成的待办划横线
- 产物分最终文件与工作文件两层，一眼区分交付物与中间产物
- 产物可一键定位到本机文件夹（复用 M13 的文件夹定位能力）
- 技能与 MCP 使用情况透明
- 记忆状态可见

## 功能需求

### 板块结构

- **F1 四板块布局**：任务监控页从上到下依次为：待办、产物、技能与 MCP、意识更新，四个独立板块，各带板块标题。所有板块可折叠展开（默认全部展开）。
- **F2 空状态**：某板块暂无数据时显示一行灰色占位文案（如「暂无待办」「本次任务未使用技能」），不隐藏板块。

### 待办

- **F3 待办清单**：展示当前任务的待办列表：每项含状态图标与描述文字；已完成的项显示完成图标且文字加删除线；进行中的项显示进行中指示。
- **F4 实时同步**：模型在执行中更新待办时（新增、完成、修改），清单随消息流实时更新，无需刷新。
- **F5 历史可回看**：刷新页面后，从落库的 signal 消息恢复当前待办状态（按任务最新一次更新为准）。

### 产物

- **F6 最终文件**：展示本任务产生的最终交付文件（【产物:】标记的文件），每项为文件行：类型图标 + 文件名。
- **F7 工作文件**：展示本任务在沙箱中产生的工作文件（脚本、中间 HTML 等），样式同最终文件但图标区分为工作文件风格。仅显示本任务期间新增或修改的文件，按修改时间倒序。
- **F8 定位文件夹**：产物行右侧提供定位图标按钮，点击调用本机能力打开该文件所在文件夹并选中（复用 M13 的 reveal 能力与端点）。
- **F9 打开预览**：点击产物行主体，在预览栏打开该文件（与现有产物标签页行为一致）。

### 技能与 MCP

- **F10 技能列表**：展示本次任务中 Agent 实际读取过的技能（去重），每项含技能图标与名称。
- **F11 MCP 列表**：展示本次任务中实际调用过的 MCP 连接器工具（按所属连接器归组，去重），每项含连接器名与工具名。

### 意识更新

- **F12 短期记忆**：显示当前任务的上下文占用状态：占用百分比 + 压缩状态（已压缩过则显示「已压缩 N 次」）。
- **F13 长期记忆**：显示跨任务记忆状态：当前实现为该任务的会话标题与压缩摘要是否存在（存在则显示「有历史摘要」，不存在显示「暂无历史摘要」）。
- **F14 语义诚实**：意识更新板块明确标注这是状态展示，不渲染模型不可解释的内部状态；数据取不到时显示占位，不编造。

### 交互与入口

- **F15 入口**：右栏以「任务监控」为默认标签页（替代原「任务摘要」入口与打开按钮文案）；原「任务摘要」功能整体移除。
- **F16 实时刷新**：监控数据在会话运行中按固定间隔轻量刷新（与现有轮询节奏一致），空闲时降低频率。

## 非功能需求

- **N1 数据源边界**：全部数据来自现有端点与消息解析（signal 消息、产物标记、工具调用记录、workspace 目录、上下文用量），不新增 AI 生成调用。
- **N2 性能**：workspace 文件列举与消息解析均轻量化；监控页打开时一次性加载，之后按 F16 刷新；不因监控页拖慢对话流。
- **N3 安全**：工作文件列举仅限沙箱 workspace 目录（复用现有边界校验）；文件名等外部文本纯文本渲染。
- **N4 中文界面**：板块标题与占位文案中文，风格与现有右栏一致。
- **N5 视觉一致**：复用现有右栏配色、字号、间距；待办状态图标、完成横线风格与图中参考一致。
- **N6 无障碍**：板块折叠可用键盘操作；完成横线之外同时有图标区分状态（不仅靠样式）。

## 不做的事

- **真正的记忆系统**：不引入 Mastra semantic recall / workingMemory 等新记忆能力，意识更新按 F12/F13 的务实映射实现。
- **待办的编辑**：不能在面板中增删改待办，只读展示模型的执行计划。
- **产物的新增操作**：不提供下载、删除、重命名等操作（M13 卡片菜单已有另存为等能力）。
- **工作文件的目录树**：不做多级目录展开，平铺按时间倒序（最多展示最近 N 条，见 plan 定额）。
- **跨任务汇总**：监控只针对当前任务（thread），不做跨任务的统计视图。
- **移动端布局**：右栏在窄屏下的特殊适配不在本期。

## 验收标准

- **AC1**（F1、F15）：打开任务右栏，看到「任务监控」为默认页，四板块依次排列，各带标题。
- **AC2**（F3、F4）：让模型执行一个多步任务并使用待办工具，面板待办清单随执行实时更新；完成后对应项图标变化且文字划横线。
- **AC3**（F5）：待办更新后刷新页面，清单状态与刷新前一致。
- **AC4**（F6、F9）：生成一个 Word 产物，最终文件区出现该文件行，点击行主体预览栏打开预览。
- **AC5**（F7）：让模型执行写脚本/中间文件的操作，工作文件区出现对应文件，按时间倒序；最终文件与工作文件图标风格可区分。
- **AC6**（F8）：点产物行右侧定位图标，资源管理器打开文件所在文件夹并选中该文件。
- **AC7**（F10、F11）：任务中读取一个技能并调用一个 MCP 工具，两区分别出现对应条目且去重。
- **AC8**（F2）：新开任务未产生任何数据时，四板块各自显示占位文案。
- **AC9**（F12、F13）：长对话任务中短期记忆区显示真实占用百分比；有历史摘要的任务长期记忆区显示「有历史摘要」。
- **AC10**（F16）：任务运行中面板数据自动更新（观察待办/工作文件变化无需手动刷新）。
- **AC11**（N3）：构造越界路径访问工作文件列举，被拒绝且面板不显示越界内容。
- **AC12**（N2）：对话流式执行期间打开监控页，对话区滚动与流式渲染无可感知卡顿。
