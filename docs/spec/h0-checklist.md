# H0 项目系统 Checklist

> 每一项通过运行代码或观察行为来验证。[ACx] 对应 spec 验收标准。

## 实现完整性

- [ ] 新建项目(名称+目录)→ 侧栏「项目」出现([AC1])
- [ ] 桌面端原生文件夹选择框可用(验证:选择目录按钮)
- [ ] 浏览器不出现项目入口(验证:浏览器侧栏无「项目」区、首页无项目选择器)
- [ ] 项目持久化:重启后端后项目仍在([AC1/AC6])
- [ ] 项目任务:首页选项目发"看看项目里有什么文件" → agent 列出真实目录内容([AC2])
- [ ] 项目写入:发"新建 index.html 写上站点标题" → 目录中真实出现文件且内容正确([AC3])
- [ ] 侧栏点击项目 → 最近任务筛选为该项目任务;切回"全部"恢复([AC4])
- [ ] 未选项目时项目工具返回"先选择项目"提示([AC5])
- [ ] 伪造 projectDir 被拒绝(验证:curl 带未注册目录,[AC5])
- [ ] 路径穿越防护(验证:file_path 带 ../ 被清洗/拒绝)

## 集成

- [ ] 线程绑定:项目任务创建后 /projects/links 可查该绑定(验证:curl)
- [ ] 重启后端:项目与绑定关系完整([AC6])
- [ ] 桌面壳过 AC1~AC3;浏览器无项目入口且现有功能正常([AC7])
- [ ] 回归:M0~M3、M6、M7 抽查正常([AC8])

## 编译与质量

- [ ] 后端启动无报错;前端 tsc 通过
- [ ] 无密钥泄漏(提交历史无 key)

## 端到端场景

- [ ] 场景 1(主流程):新建项目(选目录)→ 选项目建任务 → 列文件 → 写文件 → 目录验证 → 重启 → 项目/绑定仍在
- [ ] 场景 2(边界):未选项目问项目文件 → 提示;png/非法路径 → 拒绝
- [ ] 场景 3(筛选):两个项目各建任务 → 侧栏点击分别筛选正确
