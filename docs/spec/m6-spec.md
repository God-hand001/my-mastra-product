# M6 内置浏览器 Spec

> 产品:类千问办公的任务型 AI 助手(基于 Mastra harness)
> 编号说明:h0/m0-m3 已占用(M3 = 定时任务),m4「我的网页」、m5「扩展体系」为路线图预留,本次新增能力取 **M6**
> 前置:右侧预览面板(标签体系、产物直通、弹窗同步)已上线

## 背景

- 右侧预览面板已支持标签体系,能预览工作区文件、网盘文件、任务摘要、agent 产物
- 现状缺口:**看不了网页**。agent 联网搜索(M1)后只能给出链接文字,用户要看内容得切到外部浏览器,离开产品;agent 抓取的网页也只能以文本呈现,丢失排版与图片
- 参考产品(豆包桌面端)的新标签页首项就是「搜索或输入网址」,浏览与 AI 对话在同一窗口内完成
- M6 在预览面板内提供浏览器标签:用户可主动浏览,agent 可主动开页,当前页面内容可一键交给 agent 分析

## 关键技术约束(先行说明,决定了 F4)

普通网页**无法用 iframe 嵌入**:多数站点通过 `X-Frame-Options: DENY` 或 CSP `frame-ancestors` 拒绝被嵌套,浏览器会直接拒绝渲染。能渲染任意网页的只有 Electron 的 `webview` 标签。因此本能力**仅在桌面端可用**,浏览器环境(开发用的 Vite 网页版)必须显式降级,不做打不开的假控件。

## 目标

- G1:用户在产品内浏览网页,不必切到外部浏览器
- G2:agent 能主动打开网页给用户看(承接搜索结果、引用来源)
- G3:当前浏览的页面内容可一键交给 agent 分析,形成「浏览 → 提问」闭环
- G4:桌面端与网页端行为差异明确可见,不出现"点了没反应"

## 功能需求

- **F1 浏览器标签**:预览面板支持一种新的标签类型「浏览器」。标签内含地址栏与导航控件(后退、前进、刷新、停止加载),下方为网页渲染区。标签标题随页面标题更新,标签图标区别于文件类标签。
- **F2 地址栏输入**:地址栏接受两类输入并自动判别 —— 形如网址的直接访问(缺省补 `https://`),其余内容作为关键词提交给搜索引擎。回车触发,加载中显示进度指示。
- **F3 新标签页入口**:预览面板「新标签页」的首项为地址输入框(文案「搜索或输入网址」),提交后在当前标签打开浏览器视图。该输入框同时保留对下方「最近文件」列表的过滤能力,输入内容未提交时即时过滤。
- **F4 非桌面端提示**(已按用户决定缩减:本能力只做桌面端,不为浏览器环境做任何适配):非桌面端打开浏览器标签时,渲染区显示一句说明该能力需桌面端的提示即可,不展示空白块。不做「在系统浏览器中打开」等兜底动作。
- **F5 页面内容交给 agent**:浏览器标签工具栏提供一个动作,把当前页面的标题、网址与正文文本提交到对话输入框(不自动发送,允许用户补充问题后再发)。正文提取失败时提示原因并仅提交标题与网址。
- **F6 agent 主动开页**:agent 在回复中输出网页标记后,前端自动打开对应的浏览器标签并激活;消息正文中不显示原始标记,而是渲染为可点击的网页卡片(点击可重新打开)。标记形态与既有产物标记(`【产物:名称#路径】`)保持同一风格。
- **F7 导航状态**:后退/前进按钮在无可导航历史时置灰;加载中显示停止按钮,空闲时显示刷新按钮。
- **F8 加载失败可恢复**:页面加载失败(域名解析失败、超时、证书错误等)时渲染区显示错误信息与重试按钮,不留白屏。

## 非功能需求

- **N1 渲染隔离**:网页内容在独立的渲染上下文中执行,不能访问本产品的渲染进程、preload 桥、本地文件系统与后端接口。
- **N2 协议白名单**:仅允许 `http` 与 `https`。其他协议(`file:`、`javascript:`、自定义协议等)一律拒绝并提示。
- **N3 新窗口约束**:页面内触发的新窗口/新标签请求不弹出系统窗口,统一在产品内处理(在当前浏览器标签打开或新建浏览器标签)。
- **N4 复用既有机制**:标签的创建/切换/关闭/横向滚动、缩放、全屏、弹出独立窗口等,复用预览面板现有能力,不新造一套。
- **N5 不回退现有功能**:文件预览、产物自动开签、任务摘要、耗时统计、上下文压缩等既有行为保持不变。

## 不做的事

- 书签、浏览历史的持久化管理(仅保留会话内的前进/后退)
- 下载管理器(页面内下载行为不接管)
- 多窗口浏览、标签内嵌套标签
- 浏览器扩展/插件体系
- 网页版的真实网页渲染(技术上不可行,见「关键技术约束」)
- 无痕模式、Cookie/缓存管理界面
- agent 对网页的自动化操作(点击、填表);本次只做「读」不做「控」

## 验收标准

- **AC1**(F1):打开浏览器标签后,可见地址栏与后退/前进/刷新控件,渲染区显示网页内容;标签标题与所访问页面标题一致。
- **AC2**(F2):地址栏输入 `mastra.ai` 回车 → 访问 `https://mastra.ai`;输入 `mastra 框架` 回车 → 打开搜索引擎结果页。
- **AC3**(F3):新标签页首项为地址输入框;输入关键词但不回车时,下方「最近文件」列表按输入内容过滤;回车后进入浏览器视图。
- **AC4**(F4):在浏览器环境打开浏览器标签,渲染区显示需桌面端的提示文案,不出现空白块。
- **AC5**(F5):浏览某页面后触发该动作,对话输入框被填入包含页面标题、网址与正文摘录的文本,且未自动发送。
- **AC6**(F6):agent 回复中带网页标记时,右侧自动打开该网址的浏览器标签;消息气泡内显示网页卡片而非原始标记文本;点击卡片可重新打开该标签。
- **AC7**(F7):首次打开页面时后退按钮为置灰态;页面加载中显示停止按钮,加载完成后变为刷新按钮。
- **AC8**(F8):访问一个不存在的域名,渲染区显示错误信息与重试按钮,点击重试会重新发起加载。
- **AC9**(N2):地址栏输入 `file:///C:/` 或 `javascript:alert(1)` 时被拒绝并提示,不发生导航。
- **AC10**(N5):浏览器能力上线后,工作区文件预览、docx/pdf 预览、产物自动开签、任务摘要仍按原样工作。
