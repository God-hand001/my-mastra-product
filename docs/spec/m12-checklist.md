# M12 执行过程可观测化 Checklist

> 每一项通过运行代码或观察行为来验证，聚焦系统行为。主 agent 执行，先有证据再下结论。

## 编译与构建

- [ ] 根项目 TypeScript 编译无错误（验证：根目录 `npx tsc --noEmit`，退出码 0）
- [ ] 前端 TypeScript 编译与构建无错误（验证：`app/` 下 `npm run build`，tsc --noEmit + vite build 成功）
- [ ] `diff` 依赖已显式声明且可用（验证：根目录 `npm ls diff` 显示 8.x；`node -e "require('diff').diffLines('a','b')"` 不抛错）

## 后端 diff 数据

- [ ] 新建文件时 `project_write_file` 结果携带完整 diff（验证：真实调用写入一个新文件，观察流中 result：`isNew: true`、全部行 type 为 add、added 等于行数）
- [ ] 覆盖已有文件时 diff 含正确的增删行（验证：写入已有文件后再次覆盖修改其中几行，result.diff 中被改行成对出现 del/add，added/removed 计数正确）
- [ ] 超大内容 diff 截断（验证：写入 >60,000 字符的文件，result.diff 为 `hunks: []` 或截断后 `truncated: true`，消息体不因此异常）
- [ ] 读旧内容失败不阻断写入（验证：人为构造只读目录等场景（或代码走查确认 ENOENT 以外异常的降级分支），写入仍成功且 diff 降级为 truncated）

## 思考区块

- [ ] 模型产出推理时区块流式追加（验证：AC6 场景——流式期间「深度思考中…」区块展开、文字逐步增多；结束后标题变「已深度思考 · N 秒」并随过程收起）
- [ ] 无推理输出时无空区块（验证：AC7——用默认模型跑多步任务，若该模型不产 reasoning，过程中不出现空思考区块，叙述文字与工具卡正常）
- [ ] 历史消息思考区块可回看（验证：含推理内容的回复，刷新页面后展开摘要行，思考区块文字完整）

## 工具卡片

- [ ] 未展开即可读（验证：AC8——任一工具卡摘要行含中文动作、图标、关键参数（如具体文件路径/命令），不展开就能说出这步在干什么）
- [ ] 状态随生命周期更新（验证：AC9——工具执行中卡片显示运行中指示，数秒后自动变已完成，无需刷新）
- [ ] 文件写入卡显示真实 diff（验证：AC10——修改已有文件的回复，卡片展开见红/绿行级差异与 +N -M 统计；新建文件见全部为新增）
- [ ] 结构化结果可读（验证：AC11——展开返回结构化结果的工具卡，结果为缩进多行展示而非单行原始串，超长有截断标明）
- [ ] 失败原因未展开可见（验证：AC12——让 Agent 读取一个不存在的文件，卡片摘要行即显示失败原因摘要，展开见完整错误）
- [ ] 未知工具兜底文案（验证：AC15——调用一个连接器工具，卡片标题与状态行为可读中文兜底，无原始标识/空白）
- [ ] 历史消息卡片降级（验证：AC17——查看改动前已存在的历史消息，卡片显示工具名+参数+结果，不报错不空白）

## 步骤体与折叠

- [ ] 流式中过程内联可见（验证：AC1——多步任务流式期间，消息区依次出现思考块/叙述文字/工具卡，按时间序交错，已出现内容不消失）
- [ ] 结束自动收起、可展开回看（验证：AC2——结束后过程收为「任务已完成 ›」一行，答案完整在外；点击展开过程完整）
- [ ] 纯对话无摘要行（验证：AC3——发一句闲聊，回复不出现摘要行）
- [ ] 挂起时摘要行如实（验证：AC4——触发沙箱授权操作，摘要行显示「等待你的授权」而非「任务已完成」）
- [ ] 刷新后历史可回看（验证：AC5——多步任务后刷新页面，展开摘要行，过程与刷新前一致）

## 状态文案

- [ ] 阶段文案随实际阶段变化（验证：AC13——多步任务执行中观察输入框上方状态行，能先后看到思考/调用工具（具体动作）/执行命令等不同文案，全程不再固定「处理中...」）
- [ ] 状态行与卡片文案同源一致（验证：AC14——同一工具执行期间，状态行文案与卡片摘要行对它的中文说法一致）
- [ ] 审批等待覆盖状态行（验证：状态行在待决审批存在时显示「等待你的授权…」，秒数正常）

## 非功能

- [ ] 历史兼容（验证：AC17 已覆盖；另查 messages 轮询重挂载场景下卡片/思考块不闪错态）
- [ ] 数十步任务流畅（验证：AC18——执行一个 30+ 工具调用的长任务，过程展开状态下滚动对话区，无可感知卡顿）
- [ ] 既有功能不变（验证：AC19——重新生成正常重计时、复制/停止/审批弹窗行为不变）
- [ ] 键盘可操作、非仅颜色区分（验证：AC20——Tab+Enter 可展开/收起思考块与工具卡；diff 行带 +/- 前缀、失败态有文字标识）
- [ ] 内容转义安全（验证：写入含 `<script>` 字样的文件并让其出现在 diff 中，界面显示为文本不执行；代码走查确认无 dangerouslySetInnerHTML 新增）

## 端到端场景

- [ ] 场景 1（全流程）：「生成一个 Word 文档」类多步任务 → 流式期间可见思考块/叙述/工具卡交错推进，状态行文案跟随变化；结束后自动收起，答案与文档卡在外；展开回看过程完整，含 skill 与 html_to_docx 卡片
- [ ] 场景 2（文件修改）：「把 X 文件的标题改成 Y」→ 文件写入卡片显示行级 diff（旧标题行删除、新标题行新增）
- [ ] 场景 3（异常路径）：触发一次工具失败 + 一次沙箱授权 → 失败卡片未展开见原因；授权期间摘要行与状态行均显示等待授权；授权续跑后正常完成
- [ ] 场景 4（会话回看）：刷新页面 → 上述场景的历史消息摘要行、思考块、diff 均可回看，与实时形态一致
