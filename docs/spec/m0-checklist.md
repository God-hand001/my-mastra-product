# M0 任务基座 Checklist

> 每一项通过运行代码或观察行为来验证,聚焦系统行为。括号内为验证方式;标 [ACx] 的条目对应 spec 验收标准。

## 实现完整性

- [ ] 后端 AG-UI 端点可用:POST /agui/agent 返回流式事件(验证:T1 的 curl 命令,输出为 SSE 文本流)
- [ ] 首页呈现:左侧栏(新任务/最近任务/用户占位)+ 问候语 + 居中大输入框(验证:目测,[AC1])
- [ ] 空状态:未创建任务时显示"还未创建过任务"(验证:删库或首次启动目测,[AC1])
- [ ] 任务执行流式展示:发送消息后回答逐字出现(验证:发"你好"观察,[AC2])
- [ ] 工具调用可见:卡片显示工具名、进行中→完成状态、结果摘要(验证:发"看一下 workspace 目录里有什么文件",[AC2])
- [ ] 可中断:执行中点击停止 → 流中断、界面不崩、可继续追问(验证:长任务中途停止)
- [ ] 任务内对话带上下文:追问"刚才提到的第一个文件是干什么的"回答正确(验证:[AC3])
- [ ] 任务列表:两个任务按最近活跃排序、当前任务高亮、可删除(验证:[AC4])
- [ ] Markdown 渲染:表格、代码块语法高亮正确(验证:让 agent 输出含表格和代码的回答,[AC5])
- [ ] 文件产出链接:产出文件时给出 file:// 链接且浏览器可打开(验证:[AC5])

## 集成

- [ ] 代理生效:通过前端 5173 访问 /api/agents 返回后端数据(验证:curl http://localhost:5173/api/agents)
- [ ] 任务 = 线程:侧栏任务标题来自后端自动生成(发首条消息后,侧栏从"新任务"变为生成标题;验证:观察侧栏)
- [ ] 持久化:重启 Mastra server + 浏览器后,任务列表与执行历史仍在且可继续对话(验证:[AC4])
- [ ] 切换隔离:两个任务分别聊不同话题,切换后上下文不串(验证:任务A说"记住关键词苹果",切任务B问"我让你记住什么"应答不出)
- [ ] 前后端可独立启动:先起前端(后端未起)只报网络错误不白屏;后端起后恢复(验证:分步启动)

## 编译与质量

- [ ] 后端启动无报错:`npm run dev`(验证:观察启动日志)
- [ ] 前端构建通过:`cd app && npx tsc --noEmit && npx vite build`(验证:命令退出码 0)
- [ ] 无密钥泄漏:`git status` 中不含 .env;代码中无硬编码 key(验证:git status + grep)

## 端到端场景

- [ ] **场景 1(主流程,覆盖 AC1~AC6)**:停掉一切 → 起 Mastra server → 起前端 → 打开 5173 见首页空状态 → 输入"看一下 workspace 目录里有什么文件" → 见工具卡片与流式产出 → 侧栏出现自动生成的任务标题 → 追问上下文正确 → 产出文件链接可打开 → 重启双端 → 任务与历史仍在
- [ ] **场景 2(中断)**:让 agent 写一个长文档,执行到一半点停止 → 立即停止、界面正常,追问"继续"能接着做
- [ ] **场景 3(多任务)**:连续创建 2 个任务做不同的事 → 列表排序、标题区分正确、来回切换上下文不串
