# M14 右栏任务监控面板 Checklist

> 每项通过运行代码或观察行为验证。主 agent 执行，先有证据再下结论。

## 编译与构建

- [ ] 后端编译无错误（验证：根 `npx tsc --noEmit` 退出码 0）
- [ ] 前端编译与构建无错误（验证：`cd app && npm run build` 成功）

## 板块结构

- [ ] 四板块与入口（验证：AC1——右栏默认「任务监控」页，待办/产物/技能与MCP/意识更新依次排列，各带标题，原「任务摘要」入口不再出现）
- [ ] 空态占位（验证：AC8——新任务无数据时四板块各显示灰色占位文案，不隐藏板块）
- [ ] 板块可折叠（验证：F1——点板块标题收起/展开，默认全展开）

## 待办

- [ ] 待办实时同步（验证：AC2——多步任务执行中，面板待办清单随模型更新而变化）
- [ ] 完成态样式（验证：AC2——完成项绿勾 + 文字删除线，进行中项有进行中指示）
- [ ] 刷新恢复（验证：AC3——待办更新后刷新页面，清单状态一致）

## 产物

- [ ] 最终文件行（验证：AC4——生成 Word 产物后最终文件区出现该文件，点击进预览栏）
- [ ] 工作文件行（验证：AC5——执行写文件命令后工作文件区出现中间文件，按时间倒序，图标与最终文件可区分）
- [ ] 定位文件夹（验证：AC6——点产物行定位图标，资源管理器打开所在目录并选中）
- [ ] 20 条封顶（验证：F7/N2——工作文件超 20 条时只显最近 20 条，无报错）

## 技能与 MCP

- [ ] 技能去重展示（验证：AC7——任务中读取同一技能两次只显示一条）
- [ ] MCP 分区展示（验证：AC7——调用连接器工具后 MCP 区出现「连接器 · 工具名」条目；内置工具不误入 MCP 区）

## 意识更新

- [ ] 短期记忆（验证：AC9——长对话任务显示真实占用百分比；有压缩历史时显示「已压缩」徽标）
- [ ] 长期记忆（验证：AC9——有历史摘要显示「有历史摘要」，否则「暂无历史摘要」）
- [ ] 语义诚实（验证：F14——数据取不到时显示占位，无编造数值）

## 非功能

- [ ] 边界安全（验证：AC11——构造越界路径访问 workspace 列举被拒；面板不显示越界内容）
- [ ] 性能（验证：AC12——流式任务期间打开监控页，对话区滚动与渲染无可感知卡顿）
- [ ] 文本安全（验证：N3——文件名/任务描述含 HTML 特殊字符按纯文本显示）
- [ ] 旧摘要清理（验证：F15——grep「打开任务摘要」「openSummaryTab」无残留引用）

## 端到端场景

- [ ] 场景 1（全流程）：发多步任务（规划待办→读技能→写文件→生成产物）→ 待办实时推进并划线、技能/MCP 区出现条目、产物区出现最终+工作文件、记忆区显示占用 → 全程无手动刷新
- [ ] 场景 2（会话回看）：刷新页面 → 监控页四板块与刷新前一致（待办状态、产物列表、记忆状态恢复）
- [ ] 场景 3（降级路径）：断开前后端任一服务 → 监控页各板块显示占位或错误占位，不白屏不崩溃
