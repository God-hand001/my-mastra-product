# H0 项目系统 Spec

> 产品:类千问办公的任务型 AI 助手(基于 Mastra harness)
> 前置:M0 任务基座、M1 联网搜索、M2 个人网盘+文档问答、M3 定时任务、M6 桌面端壳已验收
> 命名:自本里程碑起,新功能以 H 系列命名(H0、H1、H2…)

## 背景

- 已有:M0~M3 + M6 验收完成;对话栏模型切换(M7)已实现
- 对标千问办公的「项目」体系:项目 = 名称 + 本地工作目录;侧栏「项目」分组;任务归属项目;agent 能处理项目目录中的文件
- 用户决策:agent 对项目目录的能力为**读写**(方案 b)—— 可列出、读取,并直接在项目目录中创建/修改文件
- 当前缺口:无项目概念;agent 的文件工具链绑定固定工作区(workspace),无法触达用户选择的任意本地目录

## 目标

- G1:项目 CRUD —— 名称 + 本地工作目录,持久化,侧栏「项目」分组展示
- G2:任务与项目绑定 —— 首页选择"当前项目"后创建的任务归入该项目
- G3:agent 项目文件能力(读写版)—— 归属项目的任务中,agent 可列出/读取/**写入**项目目录内的文件
- G4:安全边界 —— agent 只能访问已注册项目的目录;未选项目时项目工具不可用
- G5:双端可用 —— 桌面端(原生目录选择框)与浏览器(手动输入路径)均可创建项目

## 功能需求

- **F1 项目 CRUD**:后端 `/projects` 路由;项目 = {id, 名称, 工作目录};持久化于 `storage/projects.json`;支持列表/创建/删除(删除只删项目与绑定关系,线程保留)
- **F2 工作目录选择**:Electron 原生文件夹选择框(preload IPC)—— 仅桌面端
- **F3 侧栏「项目」分组**:侧栏新增「项目」区(位于最近任务上方):项目列表(名称)+「+」新建入口;空状态"暂无项目";点击项目 → 最近任务列表筛选为该项目下的任务(可切回"全部")
- **F4 新建项目弹窗**:「+ 新建项目」→ 弹窗:项目名称(必填)+ 工作目录(选填,桌面端为选择文件夹按钮,浏览器为输入框)+ 提示文案"嘉立创办公可读取并处理其中的文件";取消/创建
- **F5 首页「当前项目」选择器**:首页输入框上方下拉(无项目 / 项目列表);创建任务时,所选项目记录到线程(后端绑定接口),侧栏该项目下可见
- **F6 项目工具(agent)**:三个工具 —— 列出项目文件、读取项目文件、写入项目文件;从 requestContext 读取 projectDir 激活;未激活或目录未注册时返回明确提示(不执行)
- **F7 agent 行为**:归属项目的任务,agent 优先使用项目工具处理项目目录内的事务;系统指令说明当前项目名称与目录

## 非功能需求

- **N1 安全**:后端在执行项目文件操作前校验 projectDir 必须与已注册项目的目录完全一致(防伪造/穿越);文件名清洗
- **N2 持久化**:项目与绑定关系持久化(storage/projects.json),重启不丢
- **N3 架构**:前端仅走 HTTP(目录选择走 Electron IPC,浏览器回退输入);agent 文件操作在后端工具内用 node:fs 实现
- **N4 范围**:项目功能仅桌面端;以 window.jlcDesktop(preload 桥)检测运行环境,浏览器隐藏项目入口

## 不做的事(H0)

- 一个任务同时归属多个项目
- 项目内文件管理 UI(浏览/重命名/移动 —— 文件操作走对话)
- 项目重命名/改目录(删了重建)
- git 集成、项目模板、多人协作
- 移动端

## 验收标准

| # | 对应 | 验证方式 |
|---|------|---------|
| AC1 | F1、F2、F4 | 新建项目「我的网站」+ 选择目录 → 侧栏「项目」出现该项目;重启后仍在 |
| AC2 | F5 | 首页选择该项目 → 输入"看看项目里有什么文件" → agent 列出目录真实内容 |
| AC3 | F6、F7 | 输入"新建 index.html,写上站点标题" → 目录中真实出现 index.html 且内容正确 |
| AC4 | F3 | 侧栏点击项目 → 最近任务筛选为该项目下任务;切回"全部"恢复 |
| AC5 | N1 | 未选项目时问"看看项目文件" → agent 提示需先选择项目,不执行;伪造 projectDir 的请求被拒绝 |
| AC6 | N2 | 重启后端 → 项目列表与线程绑定关系完整 |
| AC7 | N4 | 桌面壳过 AC1~AC3;浏览器确认无「项目」入口且现有功能正常 |
| AC8 | 回归 | M0~M3、M6、M7 抽查正常 |
