# M0 任务基座 Spec

> 产品:类千问办公的任务型 AI 助手(基于 Mastra harness)
> 里程碑路线:M0 任务基座 → M1 联网搜索 → M2 个人网盘+文档问答 → M3 定时任务 → M4 我的网页 → M5 扩展体系

## 背景

- **产品定位**:对标千问办公(QwenWork)的任务型 AI 数字员工 —— 用户描述任务,agent 执行并交付产物;非传统聊天产品
- **团队背景**:同组赛马,各人用不同 harness(pi-agent / DeepSeek harness)做同类产品;本项目差异化在 Mastra harness 能力的展示(workspace、沙箱、定时、记忆)
- **后端现状**:Mastra 项目(`my-mastra-product`)已在本地跑通:DeepSeek 官方模型(`deepseek/deepseek-v4-flash`)、对话记忆、本地文件/沙箱工具、定时任务、网页抓取;仅有 Studio 调试界面,无产品 UI
- **前端选型**:assistant-ui(开源 React 聊天组件库),通过 Mastra 官方 AG-UI 集成路径(`@ag-ui/mastra`)连接后端
- **参考资料**:[Array-Ventures/coworker](https://github.com/Array-Ventures/coworker)(Apache-2.0 的 Mastra 参考实现),可借鉴其实现与代码
- **使用形态**:单人开发、本地单机使用,无登录体系,使用自己的 DeepSeek API key
- **开发节奏**:A→B→C 逐里程碑推进,本 spec 仅覆盖 M0

## 目标

- G1:提供一个可日常使用的任务式 Web 界面,完全替代 Studio 的对话功能
- G2:核心体验达到产品水准 —— 任务创建、执行过程实时可见、任务内对话、历史持久化
- G3:展示 Mastra 差异化能力:工具调用过程可见(非黑盒)
- G4:架构为后续里程碑(M1~M5)预留扩展位,不需要推倒重来

## 功能需求

- **F1 应用外壳**:左侧栏(新任务入口、最近任务列表、底部用户区占位)+ 主区(问候语 + 居中的大任务输入框);未创建任务时最近任务区显示空状态"还未创建过任务";界面文案为中文
- **F2 任务创建与执行展示**:输入任务描述 → 创建任务 → agent 流式执行;界面实时显示执行步骤、工具调用(名称/状态/结果摘要)和最终产出;执行中可停止
- **F3 任务内对话**:任务执行中/完成后,可在该任务内继续追问或补充指令,agent 携带任务上下文回应(对话服务于任务,而非独立闲聊)
- **F4 任务历史**:任务按最近活跃排序;点击任务可回看完整执行过程与产物;关闭页面或重启服务后仍在
- **F5 产出渲染**:回答支持 Markdown(标题/列表/表格/代码块语法高亮);任务产出文件时给出可打开的文件链接(沿用 harness 现有 file:// 输出约定)

## 非功能需求

- **N1 性能**:本地运行;界面操作(新建/切换任务)即时响应,流式首字延迟主要由模型决定
- **N2 安全**:API key 只存在于 `.env`(已被 git 忽略),不进代码和提交历史
- **N3 可扩展**:任务数据模型与消息渲染预留扩展位 —— M1(搜索引用)、M2(文件/网盘)、M3(定时)接入时不需要重构基座
- **N4 版本策略**:开发期锁定 Mastra 及关键依赖版本,不追自动升级
- **N5 架构边界**:前端与 Mastra server 只通过 HTTP 接口交互,前后端可独立启动 —— 为将来桌面化(Tauri)留路

## 不做的事(M0)

- 登录/多用户体系(单机单人)
- M1~M5 全部功能:联网搜索、文件上传/个人网盘、定时任务 UI、网页产物预览、技能/专家套件/连接器
- 语音输入、图片理解等多模态
- 移动端适配(桌面浏览器优先)
- 设置界面(模型/密钥沿用 `.env` 配置)

## 验收标准

| # | 对应 | 验证方式 |
|---|------|---------|
| AC1 | F1 | 启动应用 → 可见左侧栏(新任务/最近任务)+ 问候语 + 居中任务输入框;未建任务时最近任务区显示"还未创建过任务" |
| AC2 | F2 | 输入"看一下 workspace 目录里有什么文件" → 任务创建,实时显示工具调用过程(名称/状态)与流式产出;执行中点停止可中断 |
| AC3 | F3 | 任务完成后在同一任务内追问"刚才提到的第一个文件是干什么的" → agent 携带上下文正确回答 |
| AC4 | F4 | 创建 2 个不同任务 → 列表按最近活跃排序;重启服务与浏览器后,任务及执行历史仍在 |
| AC5 | F5 | 产出含表格/代码块时正确渲染高亮;产出文件时给出 file:// 链接且可打开 |
| AC6 | 整体 | 两条启动命令(Mastra server + 前端)后浏览器访问可用,全程无报错 |
