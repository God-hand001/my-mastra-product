# M2 个人网盘 + 文档问答 Spec

> 产品:类千问办公的任务型 AI 助手(基于 Mastra harness)
> 前置:M0 任务基座、M1 联网搜索已验收([m0-spec.md](./m0-spec.md) / [m1-spec.md](./m1-spec.md))
> 里程碑路线:M0 ✅ → M1 ✅ → **M2 个人网盘+文档问答** → M3 定时任务 → M4 我的网页 → M5 扩展体系

## 背景

- M0(任务基座)、M1(联网搜索)已验收;agent 已具备工具调用、上下文对话、来源引用能力
- 现状缺口:agent 虽能读写 workspace 里的文本文件,但**用户没法把自己的文档交进来** —— 手里现成的 Word/PDF/Excel 无法直接分析;千问办公的招牌能力"个人网盘 + 智能文档处理"缺位
- M2 引入两块能力:
  1. **任务附件流**:任务输入框加附件按钮(千问同款"+"),上传的文件自动随任务交给 agent 分析、总结、问答
  2. **个人网盘页**:侧栏新增"个人网盘"入口,管理已上传的文件(列表/删除/下载)
- 技术形态:文档提取**纯文本后全文进入对话上下文**(DeepSeek 长上下文足够覆盖办公文档);不做 RAG 向量检索(DeepSeek 无官方 embedding,避免引入外部嵌入服务,留待后续专门里程碑)
- 支持格式(与用户确认):txt / md / csv / json / **docx** / **pdf** / **xlsx**

## 目标

- G1:任务中可上传附件,agent 基于附件内容回答("总结这个 PDF""这份合同有什么风险点")
- G2:侧栏"个人网盘"页 —— 文件列表(名称/大小/上传时间)、删除、下载
- G3:支持七类格式;不支持的类型(图片等)给出明确提示而非静默失败
- G4:超大文档给清晰报错(超上下文预算),不静默截断、不崩溃
- G5:文件存储、解析在后端服务层完成,前后端只走 HTTP(M0 架构边界延续)

## 功能需求

- **F1 附件选择与上传**:任务输入框"+"按钮 → 弹层提供「上传新文件」与「从网盘选择」两种方式;选中的文件显示为附件条(文件名+大小+可移除);一次任务最多 5 个附件
- **F2 解析与注入**:后端接收文件 → 按类型提取纯文本(txt/md/csv/json 直读;docx/pdf/xlsx 用解析库)→ 以"文件名 + 全文"结构随任务消息交给 agent;不支持的格式(如图片)明确报错提示
- **F3 附件问答**:agent 基于附件全文完成总结、要点提取、风险分析、翻译、跨文件对比等任务;回答依据附件内容,无需联网搜索
- **F4 个人网盘页**:侧栏新增"个人网盘"入口 → 独立页面:文件列表(名称/大小/上传时间),支持删除与下载;页内也提供上传按钮
- **F5 限制与报错**:单文件 ≤ 20MB;提取后的文本超上下文预算(约 30 万字符)时返回明确报错"文件过大,暂不支持",不静默截断
- **F6 存储隔离**:上传的原始文件存入独立的网盘目录,不混入 agent 工作区(workspace)—— 避免 agent 的文件工具误改用户原件;任务中需要副本时由 agent 显式复制

## 非功能需求

- **N1 健壮性**:解析失败(损坏的 docx、加密 PDF、乱码 CSV)返回明确错误信息,任务不崩溃;agent 能看到错误并告知用户
- **N2 安全**:上传按扩展名 + MIME 双重白名单校验;文件名清洗(防路径穿越);网盘 HTTP 接口仅本机可用(延续 M0 无鉴权形态)
- **N3 性能**:20MB 内常规文档解析秒级完成;解析期间前端显示上传/处理中状态
- **N4 架构边界**:解析库只装后端;前端仅通过 HTTP 交互(M0 边界延续)

## 不做的事(M2)

- 图片/扫描件识别(多模态,后续里程碑)
- PPT/PPTX 解析
- RAG 向量检索与文档切块(全文进上下文)
- 文件内容预览(网盘页只有列表 + 下载,不做在线预览/编辑)
- 文件夹层级(网盘为平铺列表)
- 文件溯源标注("来自哪个任务")
- OCR、加密文档破解

## 验收标准

| # | 对应 | 验证方式 |
|---|------|---------|
| AC1 | F1~F3 | 上传 docx(用之前生成的嘉立创介绍文档)→ 问"总结要点" → 回答基于文档内容 |
| AC2 | F2 | 上传 PDF → 总结/提问正常 |
| AC3 | F2、F3 | 上传 xlsx → 问数据类问题("哪一列数值总和最大")回答正确 |
| AC4 | F2 | 上传 png → 明确提示"不支持的文件类型",不崩溃 |
| AC5 | F1 | 网盘已有文件 → 新任务"+"→"从网盘选择"附加 → 问答正常 |
| AC6 | F4 | 网盘页:列表显示名称/大小/时间;删除后消失;下载的文件与原件一致 |
| AC7 | F5 | 超大文本(>30 万字符)→ 明确报错"文件过大",界面与任务均不崩溃 |
| AC8 | F3 | 两个文件同时附件 → "对比这两份材料" → 跨文件对比回答 |
| AC9 | F6 | 上传文件后,workspace 目录无新增文件(原件不被 agent 工具触碰) |
