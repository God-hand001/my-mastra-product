# M3 定时任务 Spec

> 产品:类千问办公的任务型 AI 助手(基于 Mastra harness)
> 前置:M0 任务基座、M1 蠥网搜索、M2 个人网盘+文档问答已验收([m0-spec.md](./m0-spec.md) / [m1-spec.md](./m1-spec.md) / [m2-spec.md](./m2-spec.md))
> 里程碑路线:M0 ✅ → M1 ✅ → M2 ✅ → **M3 定时任务** → M4 我的网页 → M5 扩展体系

## 背景

- M0~M2 已验收:任务基座、联网搜索、个人网盘与文档问答
- 后端能力现状:`mastra.schedules` 完整 CRUD 已可用(create/get/list/update/pause/resume/run/delete),持久化于 LibSQL(重启不丢);对话中已可通过 agent 创建定时任务(`start_schedule` 工具),触发时 agent 按调度执行并把结果写进绑定的任务线程
- 现状缺口:**没有定时任务的界面** —— 用户看不到已创建了哪些定时任务、下次何时运行、也无法暂停/恢复/删除/立即执行;页面创建通道缺失;千问办公侧栏的"定时任务"入口缺位
- 创建方式(与用户确认):**页面表单创建 + 对话创建**,管理齐全(方案 A)

## 目标

- G1:侧栏新增"定时任务"入口 → 独立页面:创建 + 管理一体
- G2:页面表单创建(频率预设下拉 + 时间 + 任务描述,前端拼 cron,用户无需懂 cron);创建后自动绑定一个专属任务线程,每次触发的执行历史可在对应任务中查看
- G3:页面管理:列表(描述/频率/状态/下次运行时间)、暂停/恢复、立即执行一次、删除
- G4:对话创建定时任务的能力保留(M0 已有),页面列表统一可见、可管理
- G5:沿用 M0~M2 架构边界:后端新增 HTTP 路由封装 schedules CRUD,前端仅走 HTTP

## 功能需求

- **F1 定时任务页**:侧栏新增"定时任务"入口 → 独立页面,含"新建定时任务"按钮 + 任务列表;空状态"还没有定时任务,点上方按钮创建,或直接在对话里说'每天 9 点帮我做××'"
- **F2 表单创建**:字段 = 任务描述(必填)+ 频率下拉(**每天 / 每周·选星期几 / 工作日 / 每月·选几号 / 自定义 cron**)+ 时间点(时:分选择);提交时前端拼出 cron 表达式,后端创建;非法 cron(自定义时)由后端校验并显示明确报错
- **F3 专属任务线程**:页面创建的定时任务自动创建一个关联任务(线程),每次触发的执行历史写进该线程;列表项提供入口跳转查看
- **F4 列表展示**:每项显示 任务描述 / 频率(人类可读,如"每天 09:00"、"每周一 08:00")/ 状态(运行中·下次 09:00 / 已暂停)/ 关联任务入口
- **F5 管理操作**:每项支持 **暂停/恢复**、**立即执行一次**(马上触发,结果进关联线程)、**删除**(只删调度,保留线程历史)
- **F6 统一可见**:对话中由 agent 创建的定时任务(如"每天 9 点提醒我喝水")同样出现在列表中,同等管理
- **F7 交互细节**:创建数量不设上限(本地单人);操作后列表即时刷新;进行中的触发不阻塞页面操作

## 非功能需求

- **N1 健壮性**:调度持久化由 Mastra 承担(重启不丢);创建/操作失败给出明确错误;自定义 cron 由后端校验,非法拒绝
- **N2 安全**:接口仅本机可用;创建时自动生成关联线程,不让调度结果散落
- **N3 性能**:列表秒级加载;管理操作即时反馈
- **N4 架构边界**:后端新增 `/schedules` HTTP 路由封装 schedules CRUD;前端仅走 HTTP;执行历史复用任务线程机制,零新增存储模型

## 不做的事(M3)

- 自然语言换算 cron(表单预设 + 自定义 cron 已覆盖;NL 方案后续可加)
- 执行完成的推送通知(桌面通知等;触发结果进线程,M3 靠用户查看)
- 单独的"运行记录"列表(执行历史在关联任务线程内)
- 编辑已有定时任务(删了重建;编辑属打磨期)
- 定时调度工作流(只做 agent 调度)
- 重试/超时策略配置

## 验收标准

| # | 对应 | 验证方式 |
|---|------|---------|
| AC1 | F2、F3 | 页面创建"每天 09:00 · 汇报当前时间" → 列表出现(状态运行中、下次运行时间正确),关联任务线程已创建 |
| AC2 | F4、F6 | 对话创建一个定时任务("每天 12 点问我今天学到了什么")→ 刷新页面,列表可见两条、信息正确 |
| AC3 | F5 | 立即执行 → 关联任务线程出现新的执行内容;暂停 → 状态"已暂停";恢复 → 恢复运行中 |
| AC4 | F5 | 删除 → 列表消失;关联任务线程仍在(历史不丢) |
| AC5 | F2 | 自定义 cron 填非法值(如 `abc`)→ 明确报错,不创建 |
| AC6 | N1 | 重启后端 → 定时任务列表仍在、调度继续生效 |
| AC7 | 回归 | M0~M2 功能抽查正常(建任务/搜索/附件/网盘) |
